## Qué es un smart contract

Un contrato inteligente es código que vive en la blockchain y ejecuta lógica de forma transparente e inmutable.

```solidity
// SPDX-License-Identifier: MIT
pragma solidity ^0.8.20;

contract Counter {
    uint256 public count;

    function increment() public {
        count += 1;
    }
}
```

Así de simple es el "Hola mundo" de Solidity.

## El flujo de trabajo que usé

1. Escribir el contrato en **Remix** (web) o VS Code
2. Compilar y revisar el ABI
3. Conectar una wallet de prueba (MetaMask)
4. Desplegar en una red de test con faucets gratuitos
5. Interactuar desde un frontend con **ethers.js**

<QuoteBlock author="Mi primera lección aprendida">
La blockchain no es lenta por capricho: cada transacción es un consenso entre miles de nodos. Diseña pensando en reducir llamadas.
</QuoteBlock>

## Frontend mínimo

```jsx
import { ethers } from "ethers";

const provider = new ethers.BrowserProvider(window.ethereum);
const signer = await provider.getSigner();
const contract = new ethers.Contract(address, abi, signer);

await contract.increment();
```

<Callout type="tip" title="Tip">
Siempre verifica la cadena (chainId) y la cuenta conectada antes de firmar una transacción.
</Callout>
